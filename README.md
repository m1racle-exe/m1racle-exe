## Selected projects

### 📱 UBAYAPost (Human-Computer Interaction, team of 5)
A mobile app that puts campus events, committee recruitment and seminars in one searchable feed. I was the prototyper: a high-fidelity Figma prototype covering login to event registration, plus a heuristic evaluation with fixes for the next version.

### 🖥️ Virtual Private Server on Azure (Operating Systems, team of 5)
An Ubuntu Server 24.04 VM run like a small production server, with Apache, MySQL, PHP, SSH and FTP. I was the root user: I created the VM, wrote the project report, and set up accounts so regular users are denied `sudo` while the team lead is allowed.

### 🌐 Multi-router network in Cisco Packet Tracer
Four routers and four subnets. I grew Subnet D from four to seven devices, moving from /29 (6 hosts) to /28, then updated DHCP, the router interface and the static routes, and verified with ping in both directions.

### 🗄️ SQL Portfolio: stored procedures and cursors (Database)
Ten procedures across two databases that turn business rules (tax, allowances, loyalty points) into reusable code. Findings include an uncapped allowance that makes the lowest-paid manager the best-paid, and a tax cliff at 50,000. I also found and fixed an `IF EXISTS` bug that only appeared once a table had more than one row.
